# Changelog

## 0.1.0

First build, for World of Warcraft: Forever.

- Fifteen games: Sudoku, Gemcutter, Fireflies, Solitaire, Dig Site, Sliding Puzzle, Lanterns, Rune Lock, Pairs, Quill, Tapestry, Ricochet, Chimes, Pegs and Teahouse Tiles.
- Daily Sudoku and a daily Quill word, the same for everyone each day.
- Best scores, plays and wins for every game, trophies to earn, and a how-to-play page for each game.
- Small window that opens on the left, moves anywhere and resizes from the corner.
- Minimap button, key binding, `/campfire` and `/games`.
- Options in the window and in WoW's AddOns settings: sounds, firelight, string lights, a fireside crackle, hiding in combat, see-through when the mouse is away, raid marks for game pieces, and opening when you start fishing or take a flight path.
