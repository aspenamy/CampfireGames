# Campfire Games

Little puzzle and card games in a small cozy window for WoW Forever. Made for
fishing, flights, sitting at camp, or any other idle time.

Open it with `/campfire`, `/games`, the minimap button, or a key binding
(Key Bindings > AddOns). Drag it anywhere and drag the corner to resize it.

## Games

- **Sudoku**: easy, medium, hard and a daily puzzle, with notes and undo
- **Gemcutter**: swap gems to match three or more
- **Fireflies**: link glowing lights of one color, close loops to catch them all, and play through levels
- **Solitaire**: classic patience, draw 1 or draw 3
- **Dig Site**: dig up the site without setting off the traps
- **Sliding Puzzle**: slide the tiles back into a zone map
- **Lanterns**: light every lantern
- **Rune Lock**: work out the hidden rune code
- **Pairs**: memory matching
- **Quill**: find the five-letter word, with a daily word
- **Tapestry**: weave a picture from number clues
- **Ricochet**: knock down the wall with a bouncing ember
- **Chimes**: ring the bells back in order
- **Pegs**: jump pegs until only one is left
- **Teahouse Tiles**: match free pairs until the table is clear

Best scores, plays and wins are saved for every game, and there are trophies
to earn.

## Options

Sounds, flickering firelight, string lights, a fireside crackle, hide in combat, minimap
button, see-through when the mouse is away, raid marks for game pieces, and
opening on its own when you start fishing or take a flight path.
